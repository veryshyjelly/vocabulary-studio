Source: `monaspace-webfont-variable-v1.400.zip` from the official GitHub release
(sha256 `7e643a4c9f3994b8819308656c1c049af8c571666a74ed216764b9aae4908b40`).

The `.woff2` files are byte-identical to the release files (only the file names were shortened).
They are not glyph-subsetted: under the OFL a subsetted copy is a Modified Version and may not
carry the Reserved Font Name. Only the five variable WOFF2 files used by the app are bundled;
static, WOFF, OTF/TTF and Nerd Font builds are intentionally omitted.
